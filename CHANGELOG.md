# Changelog

## 1.0.0 — 2026-10-04

- Established the Pocket dashboard, navigation, responsive layouts, and shared integer-money validation/reporting helpers.
- Implemented transaction CRUD, confirmed deletion with undo, Local Storage persistence, filtering, searching, sorting, and repeat entry.
- Added monthly category breakdowns, six-month charts, accessible chart tables, budgets, and currency selection for empty ledgers.
- Added quick templates, local payment-text drafts, CSV exports, JSON backup imports, duplicate-ID protection, and separate sample mode.
- Added honest future Gmail/Google Pay connection previews and an implementation roadmap.
- Added domain regression tests, documented manual checks, a dependency-free local server/build, and CI/Pages workflows.

Commit history records implementation, verification, and any follow-up fixes separately. No user financial data or credentials belong in this repository.
